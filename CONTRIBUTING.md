# Contributing

Contribute only material you have the right to submit under Apache-2.0. Use a Developer Certificate of Origin sign-off (`git commit -s`); the DCO terms are at https://developercertificate.org/ . Preserve existing copyright, NOTICE and third-party notices. Do not add private Toll Bench code, credentials, real vault contents or customer fixtures.

Keep changes scoped. Include tests for data loss, changed cryptographic formats, selection boundaries and recovery behavior. Never invent cryptographic primitives. Use synthetic fixtures and no paid model calls. Discuss format changes and migration before implementation. Dependencies require license/provenance review. Security issues follow SECURITY.md.

Maintainers review releases and keep supported versions and citation metadata current. No automated dependency update may silently publish a release or deploy Toll Bench. Contributors should not imply endorsement or trademark rights beyond the license.
